# Ob-Mail 使用手册

本手册面向插件使用者，覆盖从账户配置到日常收发的全部操作。开发者视角请参阅 [design.md](design.md) 与 [ANALYSIS.md](ANALYSIS.md)。

## 1. 账户配置

打开「设置 → Ob-Mail」：

### 1.1 全局设置

| 配置项 | 说明 |
| --- | --- |
| 默认邮件存储路径 | 邮件笔记存放根目录，默认 `3-mail` |
| 默认附件目录 | 附件子目录名，默认 `attachments` |
| 邮件同步周期 | 自动收取间隔（分钟），默认 5，修改后立即生效 |
| HTML 邮件显示模式 | 见 [§6](#6-html-邮件显示模式) |

### 1.2 添加账户

点击「添加邮件账户」，展开折叠面板填写：

1. **基本信息**：账户名称（将作为存储目录名）、邮箱地址；
2. **IMAP 设置**：服务器与端口（SSL 通常 993）；
3. **SMTP 设置**：服务器与端口（465 或 587）；
4. **账户认证**：用户名；「密码/授权码」处从 **Obsidian Keychain** 选择已有关联密钥或新建一个（常见邮箱需先在邮箱服务商后台开启 IMAP 并生成**授权码**）；
5. **安全设置**：使用 SSL/TLS；「跳过证书验证」仅在自签名证书或特定代理环境下开启；
6. **签名设置**：发送时自动追加到正文末尾；
7. **代理设置**：可选，支持 http/https 代理与代理认证。

### 1.3 连接测试

每个账户面板底部提供「测试 IMAP」「测试 SMTP」按钮，建议保存配置后先测试通过再收取/发送。失败时查看控制台（Ctrl+Shift+I）获取详细错误。

## 2. 收取邮件

- **手动收取**：命令面板执行「收取邮件」，或三栏视图工具栏点击收取按钮；
- **自动收取**：插件启动后按同步周期定时收取（修改周期立即重置定时器）；
- **增量去重**：已收取的邮件按 Message-ID 记录，不会重复落盘；
- **强制重新解析**：命令「重新收取邮件（重新解析已下载邮件）」会重新解析已下载的邮件，用于显示模式变更后修复历史笔记；
- 收取结果：每封邮件生成一条 Markdown 笔记（`Notice` 提示保存路径），附件落盘并在笔记「## 附件」小节列出链接。

## 3. 三栏视图操作

命令「打开邮件客户端（Foxmail 风格）」激活：

- **左栏**：按账户列出 收件箱📥 / 已发送📤 / 草稿箱📝 / 垃圾邮件🚫，右侧角标显示未读数（无未读显示总数）；右键文件夹可「全部标记已读」；
- **中栏**：邮件列表按**邮件收发时刻由新到旧**排序（取自邮件头收发时间，与阅读/标记已读时刻无关），顶部搜索框按主题/发件人/收件人过滤；日期遵循 Foxmail 习惯（今天显示 `HH:MM`，今年显示 `MM-DD`，更早显示 `YYYY-MM-DD`）；📎 表示含附件；
  - 单击：在阅读窗格预览，**收件箱邮件预览即自动标记已读**；
  - 双击：在 Obsidian 编辑器中打开邮件原始笔记（可编辑、加双链）；
  - 右键：弹出上下文菜单——回复 / 回复全部 / 转发 / 作为附件转发 / 标记已读·未读 / 标记垃圾邮件 / 删除邮件 / 打开笔记，动作直接作用于右键的那封邮件；
  - **批量标记**：`Ctrl`+点击（macOS 为 `Cmd`+点击）可多选邮件，列表顶部出现批量操作条：标记已读 / 标记未读 / 取消选择；多选进行中暂停「预览即标读」，切换文件夹自动清空选择；
- **右栏**：阅读窗格显示邮件头与正文，操作按钮：回复 / 回复全部 / 转发 / 作为附件转发 / 标记垃圾邮件 / 标记已读·未读 / 打开笔记；
  - 邮件头可折叠：点击主题行或主题右侧的 ∧/∨ 按钮，可隐藏发件人/收件人/抄送/时间/账户等明细，折叠后显示「发件人 · 时间」摘要行，再次点击展开；右键邮件头同样弹出操作菜单；
  - 正文「附件」小节的链接可直接点击，附件以 Obsidian 默认方式在新标签页打开（pdf/图片/md 可直接预览，其他类型由 Obsidian 提供外部打开入口）；外部链接（http/https/mailto）仍交给浏览器/系统处理；
- 底部状态栏显示当前文件夹邮件数与未读数。

## 4. 写邮件

工具栏「写邮件」或命令「发送邮件」打开写信标签页：

### 4.1 收件人与联系人

- **自动补全**：在收件人/抄送/密送输入框键入时按联系人实时补全；右侧 📇 按钮打开联系人选择弹窗；
- **批量粘贴**（v1.3.0 引入，v1.4.0 增强）：直接把整段名单粘贴进输入框即可，支持
  - `姓名<邮箱>` 列表：逗号 `,，`、分号 `;；`、换行、**制表符** 任意分隔（制表符支持 Excel「姓名列 TAB 邮箱列」两列复制场景）；
  - 纯邮箱地址列表；
  - 粘贴后自动去重（与已有收件人及联系人比对），识别出的新联系人自动存入联系人库；
  - 结果反馈示例：`已添加 5 个收件人，去重 2 个，忽略 1 个无效条目`；
- 发送前所有地址统一校验，非法地址会阻止发送并提示具体条目。

### 4.2 附件（两种方式）

- **文件选择器**：点击「📎 添加附件」多选文件；
- **拖拽**（v1.4.0 新增）：直接把文件拖进写信页——
  - 从系统文件管理器拖入：支持多文件，拖入时整页虚线高亮；
  - 从 Obsidian 文件列表拖入：把 Vault 内文件作为附件发送；
  - 添加成功提示「已添加 N 个附件」，失败项单独提示；
- 附件区无附件时常驻提示「拖拽文件到此处，或点击「📎 添加附件」选择附件」；每个附件条目显示文件名、大小并可 ✕ 移除。

> 注意：附件在发送前完整读入内存，超大文件（数百 MB）可能占用较多内存。

### 4.3 草稿

- 点击「保存草稿」：存到 `{存储路径}/{账户}/草稿箱/`；从草稿再次打开后保存为**更新原草稿**；
- 关闭有修改的写信标签页会弹窗三选一：**保存草稿 / 不保存 / 取消**；
- 命令「从草稿发送邮件」可挑选草稿继续编辑。

### 4.4 发送

「发送」按钮校验账户、收件人、主题、正文后通过 SMTP 发出（正文末尾自动追加账户签名），成功后写入「已发送」目录并自动关闭标签页。

防重复发送：发送期间会弹出进度弹窗（连接服务器 → 发送/上传附件），发送按钮同时置灰，重复点击会被拒绝并提示「邮件正在发送中」；同一封邮件只会发出一次。发送失败时弹窗提示可重试，修改后可再次点击发送。

## 5. 回复 / 转发 / 垃圾邮件

在邮件笔记打开状态下执行对应命令（或三栏视图按钮）：

| 操作 | 行为 |
| --- | --- |
| 回复 | 预填发件人地址，正文引用原文，与原邮件建立 `sourceFile` 双向关联 |
| 回复全部 | 同上，并包含原邮件抄送人（自动排除自己） |
| 转发 | 预填 `Fwd:` 主题，带入原文与附件引用 |
| 作为附件转发 | 把原邮件整体（含附件）作为附件发送 |
| 标记垃圾邮件 | 状态置为垃圾邮件并移入「垃圾邮件」目录 |

## 6. HTML 邮件显示模式

设置页「HTML 邮件显示模式」三选一：

| 模式 | 效果 |
| --- | --- |
| 保留原始样式渲染（默认推荐） | 保留邮件原始 HTML 与样式，经作用域 CSS 隔离，不污染 Obsidian 其他界面 |
| 转换为 Markdown | 用 html-to-markdown 转换，最贴近 Obsidian 原生阅读体验 |
| 格式化 HTML 源码 | 安全查看原始源码，便于排查异常邮件 |

模式变更只影响**之后收取**的邮件；历史邮件可用「重新收取邮件（重新解析已下载邮件）」重刷。

## 7. 存储目录说明

```
3-mail/（可在设置中改）
├── 我的邮箱/收件箱/2026-08/周报2026-08-22-15-04-05-000000.md
├── 我的邮箱/收件箱/attachments/2026-08-22/数据表.xlsx
├── 我的邮箱/已发送/{周一日期}/…
├── 我的邮箱/草稿箱/…
├── 我的邮箱/垃圾邮件/…
└── 联系人/联系人.md
```

- 邮件笔记就是普通 Markdown：可重命名、移动（移入四个目录之一即改变所属文件夹）、加标签、被双链引用；
- 三栏视图对存储目录内的文件变化自动刷新（约 0.8 秒防抖）。

## 8. 常见问题

**Q：收取/发送失败，提示密码相关错误？**
A：确认 Keychain 中的密钥仍然有效；常见邮箱（QQ/163/Gmail 等）必须使用授权码而非登录密码；必要时在设置中重新关联密钥。旧版本遗留的明文密码会自动作为降级回退。

**Q：「manifest.json 中文乱码」？**
A：文件本身是合法 UTF-8，个别终端（如默认 GBK 编码的 PowerShell）显示乱码属显示问题，不影响插件加载。

**Q：视图里看不到某封邮件笔记？**
A：确认笔记位于 `{存储路径}/{账户}/收件箱|已发送|草稿箱|垃圾邮件/` 之下，且 frontmatter `type` 为 `邮件笔记`/`发出邮件`/`draft`；附件目录中的文件会被自动排除。

**Q：移动端能用吗？**
A：不能。插件依赖 Node 网络与文件能力，仅限桌面端（`isDesktopOnly: true`）。

**Q：换了显示模式，以前的邮件还是老样子？**
A：模式只影响新收取的邮件，执行「重新收取邮件（重新解析已下载邮件）」可重新解析。

**Q：如何卸载且保留邮件？**
A：禁用/删除插件不影响 Vault 中的邮件笔记，它们仍是普通 Markdown 文件。
