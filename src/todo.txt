二、核心 API 与组件(TypeScript)
1. SecretStorage(读写密钥)
通过 this.app.secrets 访问,异步操作:
typescript
运行
// 1. 检查 Keychain 是否启用
const isEnabled = await this.app.secrets.isEnabled();

// 2. 保存密钥到 Keychain(id 唯一标识,value 是密钥明文)
await this.app.secrets.setSecret("my-plugin-api-key", "sk-xxxxxx");

// 3. 从 Keychain 读取密钥(返回明文,仅插件自己能读)
const apiKey = await this.app.secrets.getSecret("my-plugin-api-key");

// 4. 删除密钥
await this.app.secrets.deleteSecret("my-plugin-api-key");

// 5. 获取所有密钥 ID 列表
const secretIds = await this.app.secrets.listSecrets();
2. SecretComponent(设置页密钥选择器)
在插件设置页添加 "从 Keychain 选择密钥" 下拉框,用户可直接选已存密钥,也可新建:
typescript
运行
import { Plugin, Setting, SecretComponent } from "obsidian";

// 在设置页添加密钥选择项
new Setting(containerEl)
  .setName("API Key")
  .setDesc("从 Obsidian Keychain 选择或添加 API 密钥")
  .addSecretComponent((secretComp) => {
    // 绑定插件设置里的密钥 ID(如 this.settings.apiKeyId)
    secretComp.setValue(this.settings.apiKeyId || "")
      // 选择/新建后,保存密钥 ID 到插件设置
      .onChange(async (secretId) => {
        this.settings.apiKeyId = secretId;
        await this.saveSettings();
        new Notice("API Key 已保存到 Keychain");
      });
  });

步骤 2:定义插件设置(存储密钥 ID)
typescript
运行
// 定义设置接口(只存密钥ID,不存明文)
interface MyPluginSettings {
  apiKeyId: string; // Keychain 中的密钥唯一ID
}

// 默认设置
const DEFAULT_SETTINGS: MyPluginSettings = {
  apiKeyId: ""
};

export default class MyPlugin extends Plugin {
  settings: MyPluginSettings;

  async onload() {
    await this.loadSettings();
    this.addSettingTab(new MySettingTab(this.app, this));
  }

  async loadSettings() {
    this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData());
  }

  async saveSettings() {
    await this.saveData(this.settings);
  }
}
步骤 3:设置页集成 SecretComponent
typescript
运行
class MySettingTab extends PluginSettingTab {
  plugin: MyPlugin;

  constructor(app: App, plugin: MyPlugin) {
    super(app, plugin);
    this.plugin = plugin;
  }

  display(): void {
    const { containerEl } = this;
    containerEl.empty();

    // 1. Keychain 启用状态提示
    new Setting(containerEl)
      .setName("Keychain 状态")
      .setDesc(
        this.app.secrets.isEnabled()
          ? "✅ 已启用,可安全存储密钥"
          : "❌ 未启用,请在 Obsidian 设置 → Keychain 中开启"
      );

    // 2. 密钥选择组件(核心)
    new Setting(containerEl)
      .setName("API Key")
      .setDesc("选择已存密钥,或点击下拉框右侧「+」新建密钥")
      .addSecretComponent((secretComp) => {
        secretComp
          .setValue(this.plugin.settings.apiKeyId)
          .onChange(async (secretId) => {
            this.plugin.settings.apiKeyId = secretId;
            await this.plugin.saveSettings();
          });
      });

    // 3. 测试读取密钥(可选)
    new Setting(containerEl)
      .setName("测试密钥")
      .addButton((btn) =>
        btn
          .setButtonText("测试读取")
          .onClick(async () => {
            const secretId = this.plugin.settings.apiKeyId;
            if (!secretId) {
              new Notice("请先选择或添加密钥");
              return;
            }
            try {
              const key = await this.app.secrets.getSecret(secretId);
              new Notice(`密钥读取成功(前8位:${key.slice(0,8)}...)`);
            } catch (e) {
              new Notice(`读取失败:${e.message}`);
            }
          })
      );
  }
}
步骤 4:业务代码中读取密钥
typescript
运行
// 在插件逻辑中,通过密钥ID读取真实密钥
async function callAPI(plugin: MyPlugin) {
  const secretId = plugin.settings.apiKeyId;
  if (!secretId) {
    new Notice("请先在设置中配置 API Key");
    return;
  }
  try {
    // 从 Keychain 读取明文密钥
    const apiKey = await plugin.app.secrets.getSecret(secretId);
    // 调用 API(示例)
    const res = await fetch("https://api.example.com", {
      headers: { Authorization: `Bearer ${apiKey}` }
    });
    const data = await res.json();
    console.log("API 响应:", data);
  } catch (e) {
    new Notice(`API 调用失败:${e.message}`);
  }
}
四、关键安全与规范
只存 ID,不存明文:插件设置里只存 secretId,绝对不要把密钥明文存在 data.json 或本地文件中。
错误处理:getSecret 可能抛出异常(如 Keychain 未启用、密钥不存在),必须 try/catch。
用户体验:先检查 isEnabled(),提示用户开启 Keychain;密钥读取成功后只显示前几位,不暴露完整密钥。
跨设备同步:Keychain 数据会随 Obsidian Sync 加密同步,插件无需额外处理。
